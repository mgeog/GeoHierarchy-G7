# GeoHierarchy - 世界の行政区画・都市学習マップ

世界（現在はG7主要国：日本、アメリカ、イギリス、フランス、ドイツ、イタリア、カナダ）の**行政区画と主要都市を3つの階層で体系的・直感的に学習できるWebアプリケーション**です。

---

## 🌟 特徴と主な機能

1. **🗺️ 縮尺連動（シームレスな4段階階層表示）**
   - 地図を縮小（ズームアウト）すると、**第1階層（大区分・地方・マクロ地域）**が俯瞰表示されます。
   - 地図を拡大（ズームイン）すると、自然に**第2階層（州・県・州都）**、さらに**第3階層（主要都市・大都市圏・県庁所在地）**、そして**第4階層（基礎自治体・市区町村・詳細都市）**へと情報が段階的・連動して展開されます。
   - 画面上部の切替ボタンから「縮尺連動 (Auto)」のほか、「第1階層」「第2階層」「第3階層」「第4階層」をワンクリックで選択でき、各国の国土規模に最適化されたZoomレベルへ自動移動します。

2. **📊 4段階の行政階層構造とZoomレベル設計**
   各国の地理的面積・スケールに応じた最適なZoomレベルが設定されています：

   | 国名 | 第1階層 (広域) | 第2階層 (行政区画) | 第3階層 (主要都市・首府) | 第4階層 (基礎自治体) |
   | :--- | :---: | :---: | :---: | :---: |
   | **🇯🇵 日本 (Japan)** | Zoom 4.0 (8地方) | Zoom 5.0 (47都道府県) | Zoom 6.0 (県庁所在地・主要都市) | Zoom 7.0 (全市区町村) |
   | **🇺🇸 アメリカ (USA)** | Zoom 3.6 (4大地域) | Zoom 4.6 (50州) | Zoom 5.6 (州都・大都市圏) | Zoom 6.8 (郡・基礎自治体) |
   | **🇬🇧 イギリス (UK)** | Zoom 5.5 (4構成国) | Zoom 6.3 (12地方区分) | Zoom 7.2 (各首府・中核都市) | Zoom 8.2 (特別区・ディストリクト) |
   | **🇫🇷 フランス (France)** | Zoom 5.0 (5大ブロック) | Zoom 5.8 (13地域圏) | Zoom 6.8 (レジオン首府・大都市) | Zoom 7.8 (県都・コミューン) |
   | **🇩🇪 ドイツ (Germany)** | Zoom 5.2 (4大地域) | Zoom 6.0 (16連邦州) | Zoom 7.0 (州都・主要都市) | Zoom 8.0 (郡独立市・市町村) |
   | **🇮🇹 イタリア (Italy)** | Zoom 5.2 (5大地域) | Zoom 6.0 (20州) | Zoom 7.0 (州都・主要都市) | Zoom 8.0 (県・コムーネ) |
   | **🇨🇦 カナダ (Canada)** | Zoom 3.2 (5大地域) | Zoom 4.2 (10州・3準州) | Zoom 5.2 (州都・大都市) | Zoom 6.5 (基礎自治体) |
   | **🇰🇷 韓国 (South Korea)** | Zoom 6.5 (5大広域圏) | Zoom 7.3 (17広域自治団体) | Zoom 8.3 (道庁所在地・主要都市) | Zoom 9.3 (市・郡・区) |

3. **🎯 クイズ＆学習モード**
   - 地図上の区画や都市をクリックして当てるクイズゲーム機能を搭載。
   - **ブラインドモード（白地図）**：地名を伏せて純粋な位置関係や形状から回答するトレーニングが可能。
   - **二言語表記切替**：日本語表記と現地原語/英語表記をワンクリックで並記。

4. **📑 教育用詳細ドロワー**
   - 選択した地域や都市の首府、人口、面積、管轄下の自治体一覧、解説をサイドバーで詳しく確認できます。

5. **🛰️ 多彩なリアル背景地図**
   - OpenStreetMap（標準）、フランスOSM、Esri衛星写真、地形図（等高線）、淡色グレー地図などの背景レイヤーをワンクリックで切り替え可能。

## 📚 データソース（Data Sources）

本アプリケーションで使用している地理空間データ、統計情報、行政区画データは以下のオープンデータおよび公式公表情報に基づいています。

1. **地理境界・ベクターデータ**
   - [Natural Earth](https://www.naturalearthdata.com/) - 1:50m / 1:10m Cultural Vectors (Admin-1 States & Provinces)
   - 国土交通省 [国土数値情報](https://nlftp.mlit.go.jp/ksj/)（行政区域データ・位置参照情報）
2. **タイル・地図レイヤー**
   - © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors (ODbL)
   - OpenStreetMap France
   - [OpenTopoMap](https://opentopomap.org/) (SRTM & OSM data)
   - Esri (Environmental Systems Research Institute, Inc.) World Basemap Tiles
3. **行政統計・人口・首府データ**
   - 総務省統計局（国勢調査・住民基本台帳人口）
   - U.S. Census Bureau（アメリカ合衆国国勢調査局）
   - INSEE（フランス国立統計経済研究所）
   - Statistische Ämter des Bundes und der Länder（ドイツ連邦統計局・州統計局）
   - ISTAT（イタリア国立統計研究所）
   - Statistics Canada（カナダ統計局）
   - Office for National Statistics (ONS - イギリス国家統計局)
   - 各国公式ポータル、Wikipedia（公認行政区分情報）

## 🌐 GitHub Pages での公開手順

本リポジトリは Vite の相対ベースパス（`base: './'`）に設定済みで、自動デプロイ用 GitHub Actions ワークフロー（`.github/workflows/deploy.yml`）が同梱されています。

### 方法1: GitHub Actions による自動公開（推奨）

1. このリポジトリを GitHub にプッシュします。
2. GitHub のリポジトリページで **Settings** → **Pages** を開きます。
3. **Build and deployment** の **Source** を **`GitHub Actions`** に設定します。
4. `main`（または `master`）ブランチにプッシュすると自動的に GitHub Actions が走り、数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` に公開されます。

### 方法2: 手動ビルドによる公開

```bash
# ビルド実行（distフォルダに静的HTML・JS・CSS・GeoJSONが出力されます）
npm run build
```
出力された `dist` ディレクトリの内容を `gh-pages` ブランチに配置することで公開可能です。
